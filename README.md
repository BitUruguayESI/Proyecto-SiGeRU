# Proyecto-SiGeRU
Sistema de Gestión de Residuos Urbanos - Proyecto de Pasaje de Grado 2026

## Ejecutar con XAMPP

1. Iniciá **Apache** en el panel de XAMPP.
2. Abrí la aplicación desde Apache, no con doble clic ni con Live Server:
   `http://localhost/Proyecto-SiGeRU/frontend/login.html`

Las API usan rutas relativas, por lo que se resuelven en el mismo servidor que
sirve la aplicación. En esta instalación se creó una unión desde
`C:\xampp\htdocs\Proyecto-SiGeRU` hacia esta carpeta, de modo que los cambios
hechos en el repositorio se reflejan directamente en XAMPP.
